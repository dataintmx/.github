# Security policy

## Reporting a vulnerability

Do not open a public issue or pull request for a security problem.

Report it privately:

- in public repositories, with GitHub's **Report a vulnerability** button in the repository's *Security* tab;
- in private repositories, or if the button is not available, directly to the platform lead, Arian Ventura ([@Ventura94](https://github.com/Ventura94) on GitHub, or a direct message in the Dataint Slack).

Include:

- the affected repository, service and environment;
- what an attacker could do and how to reproduce it;
- any logs or requests, with secrets and personal data removed.

We acknowledge reports within two business days.

## Leaked secrets

If a secret, token or password was committed, pasted or logged, report it the same way right away so it can be rotated. Deleting the commit or message is not enough.
